# 工作清單系統 (To-Do List)

本專案為單頁式（SPA）網頁工作清單應用程式，提供一面六條的任務規劃版面，整合 Google Firebase 雲端即時同步、AES-256 端到端加密、視覺化日曆存檔中心、密碼存取防護以及 A4 列印排版支援。

---

## 功能規格

### 1. 任務清單與版面
- **一面六條規格**：固定每頁 6 項待處理事項，適合每日工作節奏規劃。
- **核對方格切換**：前方方格可自由切換為「雙方格（□ □）」或「單方格（□）」模式，點擊可即時切換完成狀態。
- **階層式記錄**：每筆項目包含任務標題、補充說明子行、以及時間/備註欄位。
- **頁首與頁尾**：包含日期選擇、今日重點目標、備忘筆記區、完成進度統計以及簽名覆核欄位。

### 2. 日期管理與日曆存檔
- **雙模式日期輸入**：支援鍵盤直接輸入日期格式，亦可透過彈出式月曆點選，自動計算並顯示對應星期。
- **前後天快速切換**：提供快速導航按鈕，按順序切換前後日期的工作清單。
- **視覺化日曆存檔中心**：以月曆視窗呈現每日歷史紀錄，並透過標籤標示各日完成進度（已完成 6/6、進行中、無紀錄）。
- **複製任務至指定日**：支援將當前日期的清單完整複製至明天、後天、下週一或指定自訂日期，並可設定是否清空勾選狀態。

### 3. 資料儲存與雲端同步
- **Google Firebase Realtime Database 串接**：任何異動（輸入文字、勾選方格、切換日期）均自動於背景即時同步至雲端資料庫。
- **跨裝置支援**：桌機、筆記型電腦、平板與手機開啟同一個網址，即可共享最新資料。
- **離線與本機快取**：採用 LocalStorage 作為本機快取，離線狀態下仍可操作，連線後自動上傳。
- **資料匯出與還原**：提供 JSON 格式之完整資料庫備份匯出與檔案還原功能。

### 4. 安全性與端到端加密防護
- **AES-256-GCM 端到端加密**：使用瀏覽器原生 Web Crypto API，以 PBKDF2 衍生金鑰對資料庫進行 256 位元加密，雲端僅儲存加密密文，杜絕明文外洩。
- **存取密碼防護**：進入網頁時需輸入存取密碼方可解密與存取雲端資料。
- **裝置信任**：支援「在此裝置保持登入」功能，同裝置再次開啟時無需重複輸入。
- **手動重新上鎖**：工具列提供「鎖定離線」按鈕，可於公用裝置使用完畢後立即清除認證並鎖定。
- **防誤觸編輯鎖定**：工具列具備鎖定切換功能，開啟時文字欄位呈現唯讀狀態以防誤觸，方格仍可點擊記錄進度。

### 5. 視覺與輸出
- **極簡灰階主題**：全站採用黑、白、灰單色調（Monochrome / Grayscale）設計。
- **A4 比例與列印排版**：包含完整的 `@media print` 樣式設定，列印或另存為 PDF 時會自動隱藏操作工具列與遮罩，維持版面純淨。

## 系統架構

- **前端技術**：原生 HTML5、Vanilla CSS3、JavaScript (ES6+)
- **加密協定**：Web Crypto API (PBKDF2 SHA-256 + AES-GCM 256-bit)
- **字型服務**：Google Fonts (Plus Jakarta Sans, Noto Sans TC)
- **靜態託管**：GitHub Pages
- **雲端資料庫**：Google Firebase Realtime Database (REST API)

---

## 雲端資料庫規則維護（年度期限設定）

Firebase Realtime Database 支援透過時間戳記（Timestamp）設定存取期限。若設定為 1 年有效期限，每年只需至 Firebase 控制台更新一次時間戳記：

```json
{
  "rules": {
    ".read": "now < 1818687749000",
    ".write": "now < 1818687749000"
  }
}
```

- **目前有效截止時間**：至 2027 年 8 月 19 日。
- **年度更新流程**：登入 Firebase 控制台 ➔ 進入 Realtime Database ➔ 規則 (Rules) ➔ 將時間戳記遞延 1 年並點擊發布。
